= 使用網路保存庫保護您的 FSx for ONTAP 資料
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
網路保存庫 Volume 是一個隔離的且安全的儲存設備位置，用於儲存您的資料備份複本，並保護其免受勒索軟體攻擊和其他網路威脅。要建立保存庫，您需要建立一個網路保存庫 Volume，停用所有用戶端協定，在來源 Volume 和網路保存庫 Volume 之間建立複寫關係，並在網路保存庫 Volume 上建立不可變快照。

.什麼是網路保險庫？
網路保險庫是一種特定的資料保護技術，涉及將關鍵資料儲存在與主要 IT 基礎設施分開的隔離環境中。

網路金庫是一個「物理隔離」的、不可更改的、不可抹除的資料儲存庫，它不受影響主網路的威脅（例如惡意軟體、勒索軟體，甚至是內部威脅）的影響。利用不可更改且不可刪除的快照可以實現網路保險庫。

使用傳統方法的實體隔離備份包括建立空間，並將主要和次要媒體實體隔離。透過將媒體移至異地或切斷連線，惡意攻擊者無法存取資料。這可以保護資料，但可能會導致恢復時間變長。

.FSx for ONTAP網路保險庫
支援將Amazon FSx for NetApp ONTAP用作網路安全保險庫的來源和目標。

.執行
Workload Factory 提供建立網路安全架構的協助。當您聯絡NetApp表示有興趣實施網路安全保險庫後， NetApp專家會與您聯繫，討論您的需求。

請發送電子郵件至ng-FSx-Cyber​​Vault@netapp.com以開始使用。
