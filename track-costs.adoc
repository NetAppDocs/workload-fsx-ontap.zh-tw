= 在 NetApp Workload Factory 中追蹤資源成本並取得報告
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
在 NetApp Workload Factory 控制台中，以整合檢視追蹤 FSx for ONTAP 檔案系統的成本和使用情況。成本資料有助於您有效管理預算並優化資源。Workload Factory 也會為您的 FSx for ONTAP 檔案系統資源產生成本報告，您可以與利害關係人共用這些報告。



== 關於這項工作

Workload Factory 透過從 AWS Cost Explorer 取得成本資料來追蹤 FSx for ONTAP 檔案系統的成本和使用情況。追蹤的成本詳情包括：使用類型、使用 SKU、部署類型、使用量和總成本。

對於特殊資源，Workload Factory 透過綜合考慮實際效能層級使用情況、分配給已佈建但未使用空間的效能層級成本比例、按容量分配的效能配置以及容量集區使用情況來計算成本。每個組成部分均乘以其在該維度上的單位價格，再將結果加總，以確定每個資源的總成本。

在「成本」控制面板中，您可以按 AWS 帳戶、憑證、一個或多個區域以及時間範圍篩選成本和使用情況資料，以便了解您的 FSx for ONTAP 檔案系統消耗情況。資料一律以每月費率顯示。

我們使用下列權限從 AWS Cost Explorer 取得您的 FSx for ONTAP 檔案系統資源的成本和使用情況資料： `ce:GetCostAndUsage`and `ce:GetTags`。我們使用 AWS Cost API 和我們的估算值來計算總成本。`

AWS 分配標籤鍵和標籤鍵值增加了一層額外的篩選功能，可以更精確地定位特定成本。一個標籤由一個鍵和一個值組成。若要按標籤鍵和標籤鍵值進行篩選，請將標籤指派給您的 FSx for ONTAP 檔案系統。link:https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/cost-alloc-tags.html["深入瞭解 AWS 成本分配標籤。"^]

除了成本儀表板中顯示的成本資料外，您還可以產生 FSx for ONTAP 檔案系統資源的成本報告。成本報告中的資料包含特定檔案系統和磁碟區的資訊。該報告為可下載的 PDF 檔案，您可以與相關人員共用。



== 追蹤成本

Workload Factory 控制台成本儀表板中顯示的成本是基於 AWS Cost Explorer 的資料，該資料每 24 小時更新一次。

.開始之前
請確保您符合以下要求：

* 您必須link:https://docs.netapp.com/us-en/workload-setup-admin/add-credentials.html["使用_檢視、規劃和分析_權限策略授予憑證"^]在 Workload Factory 中追蹤 FSx for ONTAP 成本。
* 若要按 AWS 配置標籤進行篩選，請確保您的 FSx for ONTAP 檔案系統已指派標籤。


.步驟
. 使用其中一項登link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["主控台體驗"^]入。
. 選擇選單 image:workloads-menu-icon.png["漢堡選單圖示用於導航至儲存、EDA、AI、資料庫、VMware 和管理等工作負載。"] 然後選擇“儲存”。
. 從儲存選單中，選擇“成本”。
. 在「成本」儀表板中，透過提供以下資訊來篩選 FSx for ONTAP 資源的成本和容量資料：
+
.. *AWS 帳戶*：選擇要檢視成本資料的帳戶。
.. *憑證*：選擇具有_檢視、規劃和分析_權限的憑證。
.. *區域*：選擇要查看成本資料的 AWS 區域。
.. *成本資料範圍*：選擇要查看的成本資料的時間範圍。
.. *Allocation tag key*：（選用）選擇一個 allocation tag key 及其值，以產生與 AWS 標籤關聯的所有 FSx for ONTAP 檔案系統的詳細成本報告。
.. *Allocation tag values*：（選用）選擇與指派標籤鍵關聯的指派標籤鍵值，以產生與 AWS 標籤關聯的所有 FSx for ONTAP 檔案系統的詳細成本報告。


. 查看 FSx for ONTAP資源的*成本詳情*。




== 為您的 FSx for ONTAP 資源產生成本報告

產生特定 FSx for ONTAP 檔案系統資源的成本報告，以便與利害關係人共用。

.步驟
. 在成本儀表板中，選擇「產生報表」。
. 在「報告」畫面中，提供以下資訊：
+
.. *檔案系統*：選擇一個或多個要包含在報表中的 FSx for ONTAP 檔案系統。
.. *Volume*：（可選）選擇一個或多個 Volume 以納入報告中。




.結果
系統將產生PDF報告，可供下載。
